Troubleshooting

If you cannot access the application through the browser, try:

  1. Using a different browser
  2. Using an incognito/private browsing window
  3. Checking your browser's developer tools (F12) for error messages
  4. Accessing through a command line tool like curl: curl -v http://localhost:9002/login
  5. If direct access doesn't work, try the proxy server links above
  6. Clear your browser cache and cookies
  7. Disable any browser extensions that might be interfering
